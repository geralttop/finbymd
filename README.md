# finbymd

Учёт денег в markdown-файлах: окно Tauri 2, расчёты на TypeScript. Записи лежат обычным текстом и открываются в Obsidian или Cursor — своего сервера и аккаунта нет.

## Запуск

Нужны Node.js 20+, Rust и системные библиотеки Tauri 2.

```bash
npm install
npm run tauri dev
```

При первом запуске программа спросит папку для денег. В ней появятся `accounts.md`, `categories.md`, `recurring.md` и каталог `transactions/`.

## Установка в меню приложений

```bash
npm run install:local
```

Скрипт собирает release-бинарник, кладёт его в `~/.local/bin/finbymd`, ставит иконки и создаёт `~/.local/share/applications/finbymd.desktop`. После этого приложение появляется в меню niri и других лаунчерах. Обновление после изменений — та же команда, `.desktop` переписывается автоматически.

Если бинарник уже собран и нужно только обновить ярлык/иконку:

```bash
npm run install:local -- --no-build
```

## Проверки и сборка

## Долги

Долги лежат в `debts.md` рядом с остальными файлами. Деньги при выдаче и возврате меняют остаток счёта, но не считаются доходом или расходом: в статистике и журнале они идут отдельной строкой «Долги».

```finance
debt d1 2026-11-04 "Андрей" 65.00 BYN to "Карта" :: скинул на карту
debt-agreed d1 2026-11-06 40.00 :: договорились вернуть меньше
debt-pay d1 2026-11-20 25.00 BYN from "Карта"
```

- `to` — деньги пришли на счёт, я должен; `from` — деньги ушли, мне должны.
- `debt-agreed` меняет сумму к возврату и сохраняет разницу как прощённую.
- `debt-forgive` закрывает остаток без движения денег.
- История изменений остаётся в файле: в карточке видно, как 65 превратились в 40 и что 25 прощено.

Форма принимает дату, счёт, сумму и заметку; «Вернуть» и «Изменить сумму» добавляют строки в тот же файл. В статистике блок долгов показывает, сколько взято, возвращено, выдано и прощено за месяц, и на сколько из-за этого изменились счета.

## Планы трат

`plans.md` — список покупок с суммами, сроком и важностью:

```finance
plan p1 "Телевизор" 1200.00 BYN due 2026-12-01 priority 1 :: давно хочу
plan p2 "Наушники" 300.00 BYN priority 2
plan-done p2 2026-11-10
```

Экран «Планы» показывает, сколько денег уйдёт на открытые планы и сколько останется на счетах после них. Галочка отмечает покупку выполненной, не трогая остатки.

## Операции, категории и статистика

Форма операции подставляет сегодняшнюю дату, даже если открыт другой месяц: под датой появится подсказка, в какой файл попадёт запись. После сохранения программа сама переходит в нужный месяц.

Категория открывается кликом по чипу в разделе «Категории», по строке легенды или сектору диаграммы в статистике и по чипу категории в журнале. В истории видно всё время: сколько операций и месяцев, суммы по валютам, средняя сумма за месяц и средний чек, крупнейшая операция и разбивка по месяцам. Операции оттуда же можно править и удалять.

В статистике у каждого месяца есть кольцевая диаграмма и те же полосы: переключатель «Кольцо / Полосы» в карточке запоминается. Ниже — средний чек, число дней с тратами, крупнейшая трата и сравнение с прошлым месяцем по общим суммам и категориям. Клик по категории в любом списке открывает её историю.

## Чат

Кнопка чата — в правом верхнем углу. В настройках (шестерёнка в панели) выбирается один из двух режимов:

- **Ollama** — локальный сервер `http://127.0.0.1:11434`. Ключ не нужен, данные не покидают компьютер. Модель должна поддерживать вызов инструментов; её нужно заранее скачать (`ollama pull ...`).
- **Внешний API** — OpenAI-совместимый сервис. Нужны base URL (обычно до `/v1`), имя модели и ключ. Сообщение, счета, категории и операции выбранного месяца уходят на этот сервис.

Кнопка «Проверить» делает короткий пробный запрос и показывает ошибку, если ключ, адрес или модель не подходят.

Настройки лежат в `~/.config/com.finbymd.app/chat-settings.json` с правами `0600`, а не в папке с деньгами. Ключ не попадает в markdown и в контекст модели. Чат не читает диск напрямую: модель вызывает команды, программа проверяет аргументы теми же функциями, что и формы, и только потом пишет строки.

Счета читаются вместе с остатками; категории и повторы можно смотреть, создавать, переименовывать и удалять (с переносом строк на другую категорию). Операции: расход, доход, перевод, обмен, правка и удаление.

Долги и планы тоже доступны ассистенту: он видит их в снимке, умеет записать долг (кому и куда пришли деньги), исправить его имя, исходную сумму, счёт, направление, дату и описание, вернуть часть, изменить сумму к возврату, простить остаток, удалить долг, а также добавить план, отметить его выполненным или удалить. Исправление исходной записи (`edit_debt`) сохраняет идентификатор и историю, пересчитывает остатки; при исправлении направления меняется и направление возвратов. Новая договорённость о сумме к возврату (`change_debt`) записывается отдельным событием и не меняет исходное движение денег. Взятые и возвращённые деньги меняют остаток счёта, но не доходы и расходы — ассистент обязан использовать для них отдельные инструменты, а не `add_income`/`add_expense`.

Последнее изменение из чата отменяется кнопкой со стрелкой в заголовке панели.

## Иконка

Мастер-файл лежит в `assets/finbymd-icon.png` — это картинка из заметки про finbymd с прозрачным фоном. Из неё собирается весь набор:

```bash
npm run tauri icon assets/finbymd-icon.png
```

После замены иконки нужен `npm run install:local`, чтобы обновить и бинарник, и ярлык в меню.

## Оформление

Восемь схем: тёмная и светлая яркость, каждая в четырёх палитрах — обычная, красная, синяя, зелёная. Цвета собраны в CSS-переменные в начале `src/styles.css`; выбор хранится в `localStorage` и переживает перезапуск. Новая палитра добавляется одним блоком переменных.

Снимки экранов для проверки лежат в `docs/preview/`. Они сделаны из предпросмотра, без реальных данных.
