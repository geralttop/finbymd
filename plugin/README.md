# Плагин finbymd для Obsidian

Тот же учёт денег, что и в приложении, но внутри Obsidian: читает и пишет те же markdown-файлы, отдельного хранилища и синхронизации не требует.

## Сборка

```bash
npm run plugin:check    # типы
npm run plugin:build    # dist/plugin: main.js, manifest.json, styles.css
npm run plugin:deploy   # то же + копия в хранилище
```

`plugin:deploy` кладёт файлы в `~/my_folder/obsidian/diary/.obsidian/plugins/finbymd`. Путь меняется переменными `OBSIDIAN_VAULT` и `OBSIDIAN_PLUGIN_DIR`.

## Установка

1. `npm run plugin:deploy`
2. В Obsidian: Настройки → Сторонние плагины → включить `finbymd`.
3. Если файлы появились при открытом Obsidian — перезапустить приложение.

Папка учёта задаётся в настройках плагина. Для хранилища `diary` это `финансы`; если открывать `obsidian` как одно хранилище — `diary/финансы`.

## Экраны

- **Операции** — журнал месяца: сводка по валютам, дни, операции. Клик по операции открывает правку. Новая операция по умолчанию получает сегодняшнюю дату; если она не попадает в открытый месяц, под полем даты появляется подсказка, а после записи плагин сам переходит в нужный месяц.
- **Статистика** — итог по валютам, кольцевая диаграмма расходов с легендой, средний чек, дни с тратами и крупнейшая трата. Ниже остались полосы по категориям.
- **Счета** — остатки и начальные суммы.
- **Категории** — список с видом и числом использований. Клик по категории, сектору диаграммы или строке легенды открывает историю: суммы, средние, разбивку по месяцам и сами операции с правкой.

Слева счета и месяцы, сверху кнопки обновления и чата. На узком экране сайдбар скрывается, вместо него ряд вкладок.

## Чат

Кнопка с квадратиком справа сверху. Модель настраивается шестерёнкой в панели:

- **Ollama** — `http://127.0.0.1:11434`, модель должна поддерживать вызов инструментов;
- **Внешний API** — OpenAI-совместимый адрес и модель.

Ключ API хранится в `localStorage` устройства, а не в `data.json`, поэтому не уезжает в git вместе с хранилищем. На каждом устройстве его нужно ввести заново.

Инструменты модели: список счетов, категорий и операций, добавление расхода и дохода, удаление операции. Всё пишется в выбранный месяц; переводы и обмены чат не трогает.

## Чего нет

Переводы и обмены в журнале не показываются и не редактируются, повторов нет, отмены изменений из чата нет, форма операции открывается модалкой, а не карточкой в журнале.
