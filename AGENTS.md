# Обновление приложения

- После изменений в finbymd самостоятельно обновляй установленное приложение командой `npm run install:local`, выполнив подходящие проверки перед установкой. Не перекладывай обновление на пользователя и не спрашивай повторного разрешения.
- Это постоянное поручение пользователя от 2026-11-10; оно относится к локальной установке finbymd.
- Если ограничения среды не позволяют закончить установку, прямо сообщи, что именно не удалось. Не называй приложение обновлённым без успешной установки.
